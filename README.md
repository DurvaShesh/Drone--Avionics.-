# 🚁 Drone Avionics

> Exploring the electronics, embedded systems, and software that power autonomous unmanned aerial vehicles (UAVs).

---

## 📖 About

This repository documents my journey in learning and building modern drone avionics systems.

It combines concepts from embedded systems, electronics, robotics, IoT, and control engineering to understand how autonomous aerial vehicles sense, think, communicate, and fly.

Rather than focusing on a single project, this repository is intended to grow into a comprehensive engineering resource containing documentation, firmware, hardware designs, experiments, and practical implementations.

---

## 🎯 Objectives

- Understand UAV avionics architecture
- Develop embedded firmware using STM32
- Interface sensors and communication modules
- Explore flight control algorithms
- Document hardware and software design decisions
- Build reusable embedded software components
